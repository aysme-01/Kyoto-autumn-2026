# AYtabi｜秋の京都

## 開き方

ZIPを展開し、このフォルダーをローカルの静的Webサーバーで配信して index.html を開きます。VS Codeの「Live Server」がある場合は、index.html を右クリックして「Open with Live Server」を選べます。Pythonが使える場合は、このフォルダーで python -m http.server 8000 を実行し、ブラウザで http://localhost:8000/ を開きます。

画面HTMLと旅程JSONはHTTP経由で読み込みます。Bootstrapなどの外部ライブラリと京都の天気予報の取得にはインターネット接続が必要です。

## 統合内容

- ホームの既存ヒーロー画像、予定カード、紅葉の装飾を使用。日本時間の現在・次の予定、自動表示と手動プレビュー、残り時間、紅葉マーカーによる行程の進捗、旅のメモを実装。
- 旅行日の京都の天気、最高・最低気温、日の入りをOpen-Meteoから取得。予報期間外や通信エラー時は状態を表示。
- スポットの和紙・スクラップ風カードに「すべて」「嵐山」「東山」「京の味」の分類を追加。飲食店とカフェをエリアより優先し、祇園は東山に含める。行程に紐づいていないスポットには「候補」を表示。
- スケジュールとスポット一覧で共通の詳細モーダルを使用。営業時間、料金、見どころ、メニュー、予約、アクセス、リンクを収録情報に応じて表示。
- data/trip.json は元のファイルをそのまま収録。仮の時刻・料金・予約と、収録されていないスポット写真は元データの状態を維持。未収録の写真はカード上でアイコン表示に切り替え。

## 確認結果

全JavaScriptの構文、旅行前・進行中・予定の合間・終了後の表示、手動と自動の切替、残り時間、行程の進捗、分類ごとの件数、詳細の生成を確認。天気は模擬応答で成功・失敗の表示を確認。スマートフォン・PCでの実ブラウザ表示と操作、天気APIの実通信は未検証。
