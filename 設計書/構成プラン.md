# 京都しおり 設計メモ

## 1. コンセプト・デザイン

- 秋の京都
- 和紙・スクラップブック風
- ダークモード（夜用）余裕があれば実装検討
- スマホ優先

## 2. 画面構成

### 2.1 ホーム

##### 💡今、次に何をすればいいかがわかる画面

- ヒーロー（ホーム画像）：日付・天気・日の入り（あと何分）・最低/最高気温
- 遅れ調整ボタン：「＋15分」ボタンを押すと以降の時刻が全部ズレる
- 「いま」カード：今いる場所、滞在予定時間、進捗バー、次の予定時刻まであと何分、次の目的地までの移動方法
- 「つぎ」カード：次の場所、時間、営業時間（受付終了まであと何分）、チケット風の切り取り線、Googleマップへのボタン（現在地からの経路）
- 「今日の流れ」：5ステップのフロー（嵐山 → 昼食 → 清水寺 → 高台寺 → 夕食）
- 下に小さく：予算の合計

ホームは、開いた瞬間に「今どうすればいいか」がわかることが大事。情報は少なく、大きく。

### 2.2 スケジュール

##### 💡「時間通りに回れるか」がわかる画面

- 縦タイムライン、左に時刻、右に写真と名前
- 写真はスクラップ風
- スケジュールタイトルの横にはアイコン表示
- 移動は点線のカードで分ける（阪急 嵐山 → 河原町、など）移動項目はひとまわりちいさく、時刻表等あればそのモーダル、公式ページを表示するボタンを設置
- 各項目に、所要時間と、営業、受付時間があれば表示、予約時間があればそれも表示、タップすることでスポット内容の詳細を表示
- グルメ系はメニューモーダルを表示するボタンを表示
- 今の時間に合った項目を自動でハイライトする
- 遅れたときの代替案を、各項目の下に小さく入れる（例：清水寺が混んでいたら、まず二寧坂へ）


予定は、ただの時刻表じゃなくて、「遅れたらどうするか」まで入っているのが、痒いところに手が届くしおり

### 2.3 スポット

##### 💡「ここってどんなとこ？」がわかる画面

フィルター：嵐山 / 東山 / 行く / 候補
各スポットは、写真＋名前＋読み方＋一言
タップすると詳細モーダルが開く
開門時間・拝観料・所要時間・住所の4行
「みどころ」と「写真・楽しみ方のおすすめ」を分ける
混雑の目安と、空いている時間帯
「地図・経路を開く」「公式サイト」の2ボタン
